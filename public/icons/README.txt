ふな子 × くらり 競艇サイト用アイコン一式

内容:
- funako-kurari-favicon-32x32.png : ブラウザタブ用 PNG 32×32
- funako-kurari-favicon.ico : ブラウザタブ用 ICO（16/32/48/64px入り）
- funako-kurari-icon-192x192.png : 高解像度用 PNG 192×192
- funako-kurari-icon-512x512.png : スマホ/ホーム画面用 PNG 512×512
- funako-kurari-apple-touch-icon-180x180.png : iPhone用 PNG 180×180
- funako-kurari-icon-high-quality.svg : SVG形式（生成画像を高解像度で埋め込んだSVG）

補足:
SVGは元画像をベクター化したものではなく、高解像度PNGをSVG内に埋め込んだ形式です。
ブラウザやサイト素材として扱いやすい形にしています。
