# 多摩川競艇場｜予想用会場特徴ノート

※このノートは **買い目を作るためのものではなく、多摩川で予想するときの会場特性・水面・風・波・コース傾向を整理する資料**。  
※買い目、フォーメーション、点数指定は記載しない。  
※数値はBOAT RACE公式、多摩川公式、公開されている直近・年間データをもとに、予想で使いやすい形へ整理。

---

## 1. 多摩川の一言まとめ

多摩川は、全国24場の中でもかなり走りやすい水面。  
最大の特徴は、公式でも **「日本一の静水面」** と表現されるほど、波が立ちにくく、淡水ながら握って回りやすいこと。

江戸川のように潮や流れで激変する場ではなく、戸田のように極端な狭水面でもない。  
多摩川は、**水面が素直だからこそ、スタート・機力・ターン技術・センター勢の攻撃力がそのまま出やすい会場**として見る。

予想で特に重要なのは、次の6点。

1. **淡水・水位差なし・静水面で、潮の影響は考えなくてよい**  
2. **1コースは中心だが、全国比較では上位級ではない**  
3. **2コース差し、3コースまくり差し、4コースまくりが重要**  
4. **静水面なので、握れる選手・スタート巧者・伸び型が素直に活きやすい**  
5. **5・6コースも完全消しではなく、展開が向けば2・3着浮上がある**  
6. **展示では水面難より、機力差・行き足・ターン出口の押しを重視**

### ふな子メモ

多摩川は「荒れるから外」ではなく、**水面が良いから外もスピードを出して攻められる場**。  
1を中心に見つつも、2・3・4の攻撃力が足りているかを毎回確認したい。

## 2. 基本スペック

| 項目 | 特徴 | 予想への影響 |
|---|---|---|
| 水質 | 淡水 | 硬めの水質だが、多摩川は握りやすいとされる |
| 水位差 | なし | 潮位・干満差は基本的に考えなくてよい |
| 水面 | 日本一の静水面 | 波が立ちにくく、スピード戦になりやすい |
| 立地 | 多摩川河岸近く・標高約40m | 気圧がやや低く、モーターの力感を見たい |
| モーター | ヤマト331 | 出足・伸び・回り足の総合評価が必要 |
| チルト | -0.5〜3度 | 伸び仕様の選手は展示で確認したい |
| 進入 | 枠なり傾向が強い | 枠番とコースが結びつきやすい |

### 重要ポイント

多摩川は、淡水・水位差なし。  
江戸川や平和島のように潮の満ち引きを読む場ではない。

そのぶん、予想では次を重視する。

- スタート展示
- 行き足
- 伸び
- ターン出口の押し
- 周回展示のかかり
- モーターの実戦足
- 選手の攻める意識

## 3. コース別の基本傾向

直近公開データ・年間データでは、多摩川のコース別1着率はおおむね次のバランス。

| コース | 1着率の目安 | 評価 | 予想での扱い |
|---|---:|---|---|
| 1コース | 約52〜55%前後 | 標準〜やや低め寄り | 中心候補だが絶対視は禁物 |
| 2コース | 約14%前後 | 差し中心 | 1が甘いと差し切り候補 |
| 3コース | 約13〜14%前後 | まくり・まくり差し | 攻撃役。静水面で握りやすい |
| 4コース | 約10〜12%前後 | まくり型 | カド攻め・伸びが重要 |
| 5コース | 約5〜7%前後 | 展開型 | 3・4の攻めに乗る形が中心 |
| 6コース | 約2〜3%前後 | 1着は遠い | 展開・足色・道中力が必要 |

### 多摩川らしい数字の見方

多摩川は「日本一の静水面」という言葉から、インがかなり強い場に見えやすい。  
しかし、データ上の1コース1着率は全国上位級ではなく、むしろ中位〜やや低めの水準で推移しやすい。

その一方で、2・3・4コースが一定の攻撃力を持っている。  
つまり多摩川は、**静水面で1が残りやすい場ではあるが、センター勢も全速で攻めやすい場**。

## 4. 決まり手の特徴

### 1コース

1コースが勝つ場合は、ほぼ逃げ。  
水面が穏やかなため、1がスタートを決めて先マイできればそのまま押し切りやすい。

ただし、1コースの全国順位は高くない。  
多摩川では、1が少しでも甘いと2の差し、3・4の攻めが届く。

1を上げたい条件。

- スタート展示で遅れていない
- 起こしから行き足が良い
- 1マークで流れず、しっかりかかっている
- 2・3が壁になる
- 3・4の伸びが目立たない
- 周回展示でターン出口の押しがある
- 後半番組や優勝戦で、1の格・機力が明確

1を下げたい条件。

- スタート展示で1だけ遅れ気味
- 2の差し足が強い
- 3がスリットから先攻めできそう
- 4がカドから伸びている
- 1のターン出口が弱い
- 展示タイムは普通でも、行き足・出足が目立たない
- 人気先行で、実際の足が伴っていない

### 2コース

2コースは差し中心。  
多摩川の2コースは1着率が安定しており、1が完璧でないときの差し切り候補になる。

2を上げたい条件。

- 1のターンが完璧ではない
- 2の出足・差し足が良い
- 2がスタートで遅れない
- 2が1の懐を差せる隊形
- 3が攻めすぎず、差し場が残る
- ターン出口で押すモーター
- 捌きの上手い選手

2を下げたい条件。

- 1が強く、差し場がない
- 2の出足が弱い
- 3に先に攻められる
- 2が壁になれず後手を踏む
- 差しても出口で押さない
- 外の攻めに飲み込まれる隊形

### 3コース

3コースは多摩川の重要攻撃コース。  
まくりもまくり差しもあり、静水面で握りやすいため、スタートと伸びが良ければ一気に主導権を取れる。

3を上げたい条件。

- スタート展示で3がスリット優勢
- 2がへこみ、3に攻めるスペースがある
- 3の行き足・伸びが良い
- 1が少しでも甘い
- 3が握っても流れない
- まくり差しの角度がある
- 周回展示でターン出口の押しがある

3を下げたい条件。

- 2がしっかり壁になる
- 3の伸びが平凡
- 4に伸び負けしている
- 握ると外へ流れる
- スタート展示で踏み込みが甘い
- 1が強く、攻める隙がない

### 4コース

4コースは、まくり型の攻撃コース。  
多摩川の4コースは、決まり手としてまくりが目立ちやすい。  
カドから伸びて、内を一気に叩けるかがポイント。

4を上げたい条件。

- カドからスタートが決まっている
- 4の伸びが3より良い
- 3が壁にならない
- 内側が少しでもへこみそう
- 4のターンが流れず、出口で押している
- チルトや展示気配から伸び仕様が見える
- 静水面で全速攻めが効きそう

4を下げたい条件。

- 3に先攻めされる
- 4のターンが外へ流れる
- 内側が隊形を作る
- スタート展示でカドの迫力がない
- 伸びはあるが回り足が弱い
- 5に展開を渡すだけの攻めになりそう

### 5コース

5コースは1着率だけなら高くない。  
ただし、多摩川では3・4の攻めが発生したとき、5がまくり差しや差し込みで2・3着へ浮上することがある。

5を上げたい条件。

- 3・4が攻める流れ
- 5のまくり差しの角度が良い
- 5の回り足・出口の押しが良い
- 内側が密集し、差し場ができる
- 5の展示タイム、行き足が良い
- 道中の捌きが上手い選手

5を下げたい条件。

- 3・4が攻めない
- 内側が隊形を作る
- 5の展示が平凡
- 直線だけで回り足がない
- 外から展開を拾うだけの足がない
- 1〜4がスムーズに回りそう

### 6コース

6コースの1着は基本的に遠い。  
ただし、多摩川は静水面で外もスピードを乗せやすく、6コースの1着率が全国比較で極端に低いわけではない時期もある。

6を上げたい条件。

- 展示で足が明確に良い
- 3・4・5が攻めて前が混戦化しそう
- 6のまくり差し・差しに足がある
- スタート展示で大外から届く気配がある
- 道中で追い上げられる選手
- 内側に不安が多い

6を下げたい条件。

- 大外で足が普通
- スタート展示で遅れている
- 内側がスムーズに隊形を作る
- 水面が穏やかで1〜3が自然に残りそう
- 展開待ちだけで自力要素がない

## 5. 進入・枠番の見方

多摩川は枠なり進入がかなり多い。  
直近データでも、1枠はほぼ1コース、2枠はほぼ2コース、3枠はほぼ3コースに入る。

そのため、基本は枠番とコースを素直に結びつけてよい。  
ただし、枠なりだから内有利と決めつけない。

### 進入で見るポイント

- 1が深くならず、行き足を保てるか
- 2が差しに構えられるか
- 3がスリットから攻めるか
- 4がカドから伸びるか
- 5が4の攻めに乗れるか
- 6が大外から展開に参加できる足か

### 多摩川で注意すること

多摩川は静水面なので、センター勢が全速で仕掛けやすい。  
つまり、1が逃げやすい条件でもあるが、3・4が攻めやすい条件でもある。

**静水面＝インだけ有利** ではなく、  
**静水面＝全艇が力を出しやすい** と考える。

## 6. 潮・水位の考え方

多摩川は淡水で水位差なし。  
潮の満ち引きは予想の主軸にしない。

### 見なくてよいもの

- 上げ潮
- 下げ潮
- 潮止まり
- 大潮・中潮・小潮による水面変化
- 潮位差によるターンの変化

### 代わりに見るもの

- 風向き
- 風速
- 波高
- スタート展示
- 展示タイム
- 一周タイム
- まわり足
- 直線気配
- モーター評価

### ふな子メモ

多摩川は、潮で迷わなくていいぶん、展示の見方が大事。  
「潮が悪いから仕方ない」ではなく、**足が良いか、攻められるか、回れるか**を素直に判断する。

## 7. 風・波の読み方

多摩川は「日本一の静水面」とされるほど、波が立ちにくい。  
そのため、江戸川のように水面難度で大きく崩れる場ではない。

ただし、屋外水面なので風は必ず確認する。  
静水面だからこそ、風で少し条件が変わると、スリット隊形やターンの流れ方に差が出る。

### 追い風

追い風では、1コースがスタートを合わせやすく、先マイしやすいことがある。  
一方で、強めの追い風になるとターンが流れ、差しが入りやすくなることもある。

追い風で上げたい要素。

- 1の起こしと行き足
- 2の差し足
- ターンで流れない回り足
- 出口で押すモーター
- 3・4が握っても流れないか

追い風で下げたい要素。

- 1が先マイしても外へ流れる
- 3・4が握って流れる
- 直線だけ良くてターンが弱い
- 差しても出口で押さない艇

### 向かい風

向かい風では、スタートが届きやすくなり、センター勢が攻めやすくなる。  
多摩川は握りやすい水面なので、3・4の全速攻めに注意したい。

向かい風で上げたい要素。

- 3コースのまくり気配
- 4コースのカド攻め
- スタート展示でスリット優勢な艇
- 握っても流れない回り足
- 伸び型モーター

向かい風で下げたい要素。

- 1がスタートで遅れる
- 2が壁にならない
- センターに伸び負けしている内枠
- 強風で起こしが不安定な選手

### 横風

横風では、ターンマークを外す艇が出ることがある。  
静水面の多摩川でも、横風が強いと握った艇が外へ流れたり、差し艇の角度が変わる。

横風で見たいポイント。

- 1がマークを外さず回れるか
- 2の差しが入りやすいか
- 3・4が握って流れないか
- 5のまくり差し角度があるか
- 周回展示で艇が安定しているか

### 波高がある日

多摩川は波が立ちにくい場だが、波高がある日は通常よりも展示重視。  
特に、普段は全速で握れる水面だからこそ、波で流れる艇は目立つ。

波がある日の考え方。

- 1は逃げられるかより、まず流れないか
- 2は差し場を作れるか
- 3・4は握っても外へ流れないか
- 5・6は前崩れの展開拾い評価
- 展示タイムより、ターン安定と出口の押し

## 8. 季節別の傾向

### 春：3〜5月

春は1コースが約54%台。  
2コースの1着率が高めで、3・4は攻め役、5は3着以内の展開拾いが目立つ。

春の見方。

- 1は中心候補
- 2差しを必ず確認
- 3が攻めるスペースを持つか見る
- 4は3がへこむか、伸び優勢なら評価
- 5は3着以内の浮上に注意

### 夏：6〜8月

夏は1コース1着率がやや下がり、3コースの1着率が上がりやすい。  
静水面でスピード戦になりやすく、3・4の攻めが効く。

夏の見方。

- 1は過信しすぎない
- 3コースのまくり・まくり差しを高めに見る
- 2の差し残りを確認
- 4はカド攻め、5は展開拾い
- 暑さで出足・回り足が落ちる艇を下げる

### 秋：9〜11月

秋は1コースが約52%台で、2・3・4のバランスも比較的良い。  
5コースの3着以内浮上も見たい時期。

秋の見方。

- 1の展示が良ければ中心評価
- 2の差し、3の攻め、4のカドを比較
- 5は2・3着の展開浮上に注意
- 風が弱ければ機力・技量が素直に出る
- 道中力のある選手を上げる

### 冬：12〜2月

冬は1コース1着率が上がりやすい。  
一方で、4コースの1着率も上がる時期があり、センター〜カドの攻めも無視できない。

冬の見方。

- 1は季節的にやや信頼しやすい
- 2は差し・2着残りを確認
- 3は夏ほど強くないが、足が良ければ攻める
- 4は1着率が上がりやすく、カド気配を確認
- 気温低下でモーターの足色変化を見る

## 10. 展示で見るべきポイント

多摩川で予想前に必ず見る項目。

### スタート展示

- 1が遅れていないか
- 2が差しに構えられるか
- 3がスリットで出ていないか
- 4がカドから伸びていないか
- 5が4の攻めに乗れるか
- 6が大外から展開に参加できる足か

多摩川では、特に3・4のスタート展示を重視。  
静水面で全速攻めが効きやすいため、3・4がスリットで優勢なら1の信頼度を少し下げる。

### 周回展示

周回展示では、タイムだけでなく「ターン出口の押し」を見る。

見るべき項目。

- 1マークで流れないか
- ターン出口で押しているか
- 差し構えの艇が立ち上がるか
- 握る艇が外へ流れないか
- 直線で伸びるだけでなく、回ってから前に出るか
- 引き波を越えた後に失速しないか

### 展示タイム

展示タイム上位は評価材料。  
多摩川は水面が素直なので、展示タイムや一周タイムが比較的レース足に反映されやすい。

ただし、展示タイムだけで判断しない。  
特に重視したい順番。

1. スタート展示の行き足  
2. 1のターン安定  
3. 2の差し足  
4. 3・4のスリット気配  
5. ターン出口の押し  
6. 展示タイム、一周タイム、直線タイム

## 11. モーター・チルトの見方

多摩川は静水面で、モーターの良し悪しが素直に見えやすい。  
また、チルト角度の選択幅が広いため、伸び仕様の選手は展示で必ず確認する。

### モーターで上げたい要素

- 行き足が良い
- スリット後に伸びる
- 回ってから押す
- 一周タイムが良い
- 直線タイムが良い
- 展示で艇が暴れない
- 出足と伸びのバランスが良い

### モーターで下げたい要素

- 起こしが重い
- スリット後に置かれる
- ターン出口で止まる
- 直線だけ良くて回れない
- 展示タイムだけで、周回が弱い
- 展示で安定していても押しがない

### チルトを見る場面

- 4・5・6が伸び仕様にしている
- スタート展示で外が明らかに伸びる
- 3・4がまくりに行ける隊形
- 1・2が伸び負けしている
- ただし、伸び仕様でも回り足が落ちるなら減点
